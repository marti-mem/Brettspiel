# Fotos für die Spielfiguren

Lege hier pro Person ein Foto ab (am besten ein Porträt, quadratisch, Gesicht mittig).
Der Dateiname muss genau so heißen:

| Figur   | Datei                         |
|---------|-------------------------------|
| Jakob   | `jakob.jpg`                   |
| Mama    | `mama.jpg`                    |
| Mami    | `mami.jpg`                    |
| Oma     | `oma.jpg`                     |
| Opa     | `opa.jpg`                     |
| Birgit  | `birgit.jpg`                  |
| Gerhard | `gerhard.jpg`                 |
| Lukas   | `lukas.jpg`                   |
| Astrid  | `astrid.jpg`                  |
| Martin  | `marti.jpg`                   |

Erlaubt sind `.jpg`, `.jpeg`, `.png` und `.webp`. Danach `npm run build` ausführen.
Fehlt ein Foto, wird ein farbiger Platzhalter gedruckt.

## Stand

Fertig (Pixar-Stil mit Weihnachtsmütze): alle 10 Figuren.
